# 면허 다시, 제대로

대한민국 운전면허 학과시험을 준비하는 독자 제작 학습 웹사이트입니다.

## 제공 기능

- 독자 제작·검증 문항 250개
- 오늘의 10문제
- 랜덤 10문제·주제별 전체 문제 학습
- 보행자·보호구역 학습 가이드와 확인 문제
- 브라우저 기반 학습 기록
- 문제별 설명과 공식 법령 링크
- 모바일 반응형 UI
- 서비스 소개와 문항 제작·검증 원칙
- 개인정보처리방침, 쿠키 안내, 이용약관, 문의 페이지
- 검색엔진용 sitemap·robots와 소셜 공유 카드

## 안내

- 한국도로교통공단 공식 문제은행 문장을 복제한 서비스가 아닙니다.
- 법령과 시험 기준은 바뀔 수 있으므로 시험 전 공식 원문을 다시 확인하세요.
- 학습 기록은 현재 브라우저의 로컬 저장소에 보관됩니다.
- 운영 도메인은 `https://road10.ai`입니다.

## 저장소 구성

공개 배포에 승인된 웹 파일과 독자 제작 자산만 포함합니다. 제작 과정의 감사자료, 내부 참고자료, 공식 문제은행 원본은 별도 비공개 저장소에서 관리합니다.

현재 사용 방식

road10.ai는 회원가입 없이 학습을 이어갈 수 있도록 브라우저 로컬 저장소(localStorage)를 사용합니다. 로컬 저장소는 쿠키와 다르지만 브라우저에 정보를 저장한다는 점에서 함께 안내합니다.

Google Analytics 방문 통계는 선택형으로 운영합니다.

분석 저장소는 기본 거부 상태입니다. 분석 허용을 선택한 경우에만 Google Analytics 쿠키를 사용할 수 있습니다. Google AdSense 실제 광고는 아직 비활성 상태입니다.

브라우저 저장 항목

저장 키 내용 용도
driving-study-original-v1 오늘의 문제 ID, 답안, 진행 위치, 날짜 오늘의 10문제 이어풀기
driving-question-lab-session-v1 문제랩 세트, 답안, 진행 위치 진행 중 학습 복원
driving-question-lab-history-v1 완료 날짜, 점수, 정오답, 문제 ID 학습 기록·오답 복습
road10-consent-v1 Analytics 분석 허용 또는 거부 선택과 변경 시각 동의 선택 유지·Consent Mode v2 적용

이 정보는 기본적으로 이용자의 기기에만 있으며 운영자 서버로 자동 전송되지 않습니다.

Google Analytics와 Consent Mode v2

Google Analytics 4 측정 ID G-4TVC0YE9Y5를 사용해 페이지 조회, 유입 경로, 기기 유형, 신규·재방문, 퀴즈 시작·완료와 같은 통계를 확인합니다. 문제 답안 원문이나 브라우저에 저장된 학습 기록 전체를 Analytics로 보내지 않습니다.

저장 항목 사용 조건 일반적인 용도
_ga, _ga_* 이용자가 분석 허용을 선택한 경우 방문자와 세션 구분, 이용 통계 생성
쿠키 없는 Consent Mode 신호 분석 거부 상태에서도 전송될 수 있음 동의 상태 전달과 집계·모델링용 기본 측정

Consent Mode v2의 analytics_storage, ad_storage, ad_user_data, ad_personalization은 최초 방문 시 모두 거부 상태로 시작합니다. 현재 선택 UI는 Analytics 저장소만 변경하며 광고 관련 저장소는 계속 거부 상태로 둡니다.

Google 광고 활성화 시

Google AdSense가 활성화된 페이지에서는 Google과 광고 파트너가 광고 제공·측정·부정 이용 방지를 위해 쿠키 또는 유사 기술을 사용할 수 있습니다. 이용 지역과 동의 선택에 따라 맞춤 또는 비맞춤 광고가 제공될 수 있습니다.

  • Google 광고 기술 안내
  • Google 광고 개인 최적화 설정
  • 파트너 사이트에서 Google이 데이터를 사용하는 방식

유럽경제지역, 영국, 스위스 등 동의가 필요한 지역에는 Google이 인증한 동의 관리 플랫폼(CMP)을 사용해 선택권을 제공합니다.

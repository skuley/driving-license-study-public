3. 브라우저에 저장되는 학습 기록

학습 기록은 브라우저의 로컬 저장소(localStorage)에 저장됩니다. 운영자 서버로 자동 전송되지 않으며, 같은 기기와 같은 브라우저에서만 기본적으로 확인할 수 있습니다.

  • 브라우저 사이트 데이터 삭제 시 기록도 삭제됩니다.
  • JSON 내보내기로 직접 백업할 수 있습니다.
  • 공용 기기에서는 이용 후 브라우저 데이터를 삭제하세요.

자세한 저장 키와 삭제 방법은 쿠키·로컬 저장소 안내에서 확인할 수 있습니다.

4. 외부 서비스와 국외 처리 가능성

GitHub Pages

사이트는 GitHub Pages에서 호스팅됩니다. 사이트 제공과 보안 과정에서 GitHub가 접속 기술정보를 처리할 수 있으며, 해당 처리는 GitHub의 인프라와 GitHub 개인정보처리방침에 따릅니다. road10.ai 운영자는 GitHub가 보유한 원시 접속 로그를 직접 제공받지 않습니다.

Google 광고 서비스

향후 Google AdSense가 활성화되면 Google과 광고 파트너가 광고 제공, 빈도 제한, 측정, 부정 이용 방지를 위해 쿠키, IP 주소, 기기·브라우저 정보, 광고 상호작용 정보를 처리할 수 있습니다. 광고 활성화 시 실제 적용 내용과 동의 설정을 이 방침과 쿠키 안내에 반영합니다.

Google 파트너 사이트 데이터 사용 방식과 Google 개인정보처리방침에서 세부 내용을 확인할 수 있습니다.

제3자 제공

운영자는 이용자의 개인정보를 판매하지 않습니다. 법령에 근거한 요청이나 이용자 동의가 있는 경우를 제외하고 문의 정보를 독립된 제3자에게 제공하지 않습니다.

5. 파기와 안전조치

보관 목적이 끝난 문의 정보는 복구가 어렵도록 삭제합니다. 학습 기록은 운영자 서버에 없으므로 이용자가 브라우저 설정에서 직접 삭제합니다. 운영자는 공개 저장소에 비밀번호·비밀키를 포함하지 않고, 도메인과 배포 계정의 접근 권한을 제한합니다.

6. 이용자의 권리

이용자는 문의를 통해 자신의 문의 정보에 대한 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다. 본인 확인이 필요한 경우 최소한의 확인 절차를 요청할 수 있습니다.

브라우저 학습 기록은 해당 기기에서 직접 확인·내보내기·삭제할 수 있습니다. 브라우저 데이터를 삭제하면 운영자가 복구할 수 없습니다.
